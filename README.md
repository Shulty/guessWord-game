# GuessWord game
Игра, работающая по принципу Wordle, на русском языке с выделением слов по темам и категориям.
![gameplay](src/images/Gameplay1.png "gameplay")
___
## Features
- Проверка слов на существование при помощи Yandex спеллер API
- Кастомный Input, переключение между буквами при помощи JavaScript
- Адаптив под все устройства
